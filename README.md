# Sales Data Analytics Project

A beginner-friendly portfolio project using Python, pandas, and Matplotlib.

> The CSV contains fictional sample records for learning, not real customer data.

## Features
- Calculate revenue from quantity and unit price.
- Summarize revenue by month, city, and category.
- Find the top five products by revenue.
- Export summary CSV reports and create charts.

## Requirements
Python 3.10+, pandas, Matplotlib.

## Run
```bash
pip install -r requirements.txt
python analyze_sales.py
```

Generated reports and charts are saved in `outputs/`.

## Portfolio summary
Analyzed a sample sales dataset with Python, pandas, and Matplotlib; calculated revenue; grouped results by month, city, and category; and generated CSV summaries and visualizations.
